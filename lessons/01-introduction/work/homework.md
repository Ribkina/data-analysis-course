## H3. Инструменты

Series — одномерная структура данных pandas, представляющая один столбец таблицы.
Пример: df["action_taken"].
DataFrame — двумерная структура данных, представляющая таблицу со строками и столбцами.
Пример: df[["action_taken", "loan_amount"]].
nrows и head
nrows — параметр функции pd.read_csv(), который ограничивает количество строк, загружаемых из файла.
Пример: pd.read_csv("decisions.csv", nrows=5).
head() — метод DataFrame, который возвращает первые строки уже загруженной таблицы.
Прмер: df.head().
Метод и атрибут
Метод выполняет действие и вызывается со скобками. Например, df.head().
Атрибут возвращает свойство объекта и вызывается без скобок. Например, df.shape.
